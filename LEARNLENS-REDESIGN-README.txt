LEARNLENS — UI REDESIGN

What changed:
- Guest home page opens directly on Sign In.
- New two-panel LearnLens sign-in/sign-up experience with colorful gradient, modern cards and Teacher/Student selector.
- Removed TeacherBeta badge from the header and renamed app branding to LearnLens.
- Removed the old footer from the UI.
- Applied consistent colors, form fields, buttons and card styling to existing screens.
- Existing authentication forms, routes and business logic are retained.

Run the project from the tcherly-main folder using the existing project instructions:
1. Open the folder in VS Code.
2. Open Terminal > New Terminal.
3. Run: yarn
4. Run: yarn install:c
5. Configure .env and client/.env from their .env.example files if not already present.
6. Ensure the configured MongoDB/server dependencies are available.
7. Run: yarn dev
8. Open the local URL shown in the terminal.

Note: The app has not been fully run against a configured backend in this environment. If a build or runtime error appears, share the exact terminal error.
